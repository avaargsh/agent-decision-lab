## Interpretation

The first run is useful because it reveals three concrete things:

1. the Frozen-LM candidate-logit pipeline executes end to end on a real Qwen checkpoint;
2. raw confidence is strongly miscalibrated on this fixture;
3. candidate wording/prompt construction currently biases the model toward `read_metrics`, so dataset and prompt design need to be treated as experimental variables.

The next run adds p50/p95 latency, tokens processed per decision and runner hardware evidence.
