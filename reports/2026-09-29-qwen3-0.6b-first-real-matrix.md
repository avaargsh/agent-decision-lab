# First real benchmark matrix

This artifact promotes the already archived Qwen3-0.6B same-run result into the repository's machine-readable benchmark matrix format.

It does **not** make a model-quality claim. The test set contains only four synthetic tool-routing cases; both arms achieved 2/4 accuracy.

The useful systems result from this run is latency:

- A / batched Frozen candidate logits: p95 917.19 ms
- E / autoregressive structured output: p95 4619.10 ms

The next required experiment is a larger independently labelled corpus with confidence intervals and stable calibration evaluation. Arms B/C/D remain intentionally absent until measured results exist.
