| Metric | Batched Frozen logits | Structured output |
| --- | ---: | ---: |
| Accuracy | 0.5000 | 0.5000 |
| Brier | 0.1849 | 0.1900 |
| ECE | 0.2119 | 0.1500 |
| Mean latency | **877.17 ms** | 4567.35 ms |
| p50 latency | **872.73 ms** | 4560.05 ms |
| p95 latency | **917.19 ms** | 4619.10 ms |
| Mean tokens processed / decision | 125.5 | 101.5 |
| Coverage @ 0.5 | 0.25 | 1.00 |
| Selective risk @ 0.5 | 0.00 | 0.50 |

Within the same runner, batched Frozen scoring was approximately **5.2x faster** in mean wall-clock latency than autoregressive structured generation.

The Frozen path processed more aggregate sequence tokens because every bounded candidate continuation is scored, but those candidates are evaluated in one batch. This is why token count alone is not equivalent to wall-clock compute cost.

## What changed from the earlier implementation

Old reference path:

```text
Prompt + Candidate A -> Forward
Prompt + Candidate B -> Forward
Prompt + Candidate C -> Forward
```

Optimized path:

```text
              Candidate A
             /
Prompt ----- Candidate B ----> one batched forward
             \
              Candidate C
```

The experiment framework also caches test-set model scores so raw and calibrated reports reuse the same inference result instead of running the model twice.

That is visible in the artifact: raw and calibrated reports carry the same per-case latency for each arm.

## Candidate behavior

Frozen logits still selected `read_metrics` for every test case.

Structured output still selected `read_logs` for every test case.

Both achieved 2/4 accuracy. Therefore the dataset remains too small to support a quality conclusion, but it is already useful for detecting method-specific candidate bias.

- raw test ECE: 0.1500

- raw Brier: 0.1900

The Frozen calibration improving calibration-set NLL but worsening held-out test ECE is exactly why a four-example calibration split is not sufficient for a stable calibration claim.

## Engineering conclusion

This run supports a systems hypothesis, not a model-quality hypothesis:

> For a small bounded candidate set, candidate-logit scoring becomes substantially more attractive once candidate continuations are batched and autoregressive generation is removed from the hot path.

The next research requirement is a larger independently labeled corpus so accuracy, calibration and Risk-Coverage can be interpreted with meaningful confidence intervals.
